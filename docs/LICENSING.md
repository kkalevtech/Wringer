# Licensing

## Application licence

**GPL-3.0-or-later.** Rationale in `DECISIONS.md` ADR-004.

This choice means we may bundle copyleft engines (GPL, AGPL) without
negotiating anything. If that ever changes, every entry below must be
re-checked *before* the licence change, not after.

## Bundled components

| Component | Licence | Obligation for us |
|---|---|---|
| libvips | LGPL-2.1-or-later | Redistribute licence text; provide the corresponding source or a written offer; allow replacement of the library. Driving it as a separate process keeps this simple. |
| libheif (if bundled for AVIF/HEIC) | LGPL-3.0 | Same as libvips. |
| AV1 encoder (aom / rav1e / svt-av1) | BSD-2 / BSD-3 / BSD | Redistribute licence text and copyright notices. |
| Various libvips dependencies (glib, libjpeg-turbo, libpng, libwebp, zlib, lcms2, expat) | LGPL-2.1, BSD, zlib, MIT | Redistribute licence text. |
| Tauri, Rust crates, npm packages | MIT / Apache-2.0 mostly | Verify per crate; `cargo-about` and a licence checker generate the list. |

## Rules

1. **Every bundled binary is pinned to an exact version with a recorded
   SHA-256** in `scripts/fetch-engines.ps1`. No "latest".
2. **`THIRD-PARTY-NOTICES` is generated by the build**, not written by hand,
   and ships inside the installer.
3. **No new engine without a licensing review** recorded in `DECISIONS.md`.
4. Keep a written offer to provide engine source alongside the installer, so
   LGPL obligations are satisfied without shipping full sources in the package.

## Engines to think hard about before adding

These are out of scope for v1 but are traps if added carelessly:

- **Ghostscript** — dual AGPL / paid Artifex commercial. Under GPL-3.0 we may
  ship the AGPL build; a proprietary build could not.
- **FFmpeg** — LGPL by default, GPL if built with `--enable-gpl`. Record which
  build we ship, because it decides whether a future proprietary edition is
  even possible.
- **7-Zip** — LGPL, except the bundled RAR decoder, which carries an
  additional restriction.
- **ImageMagick** — permissive itself, but it delegates to Ghostscript for
  PostScript and PDF. Its delegates are the hazard, not its licence text.
- **unrar / RARLAB** — redistributing the UnRAR source is restricted. Avoid.

## Checklist before any release

- [ ] `cargo-about` (or equivalent) run; output diffed against the last release.
- [ ] Every entry in `fetch-engines.ps1` has a version and a hash.
- [ ] `THIRD-PARTY-NOTICES` present in the installer and readable.
- [ ] `LICENSE` in the repo is GPL-3.0 and the README states it plainly.
- [ ] A written offer for engine source exists and is referenced.
